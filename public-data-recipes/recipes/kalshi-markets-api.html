Read open Kalshi prediction-market prices (public API)

Tested by hand on 2026-10-29 · No API key needed · Official docs

Kalshi is a CFTC-regulated US exchange. Its market-data endpoints are public, so reading prices needs no login.

Endpoint

https://api.elections.kalshi.com/trade-api/v2/events?status=open&with_nested_markets=true

Steps

  1. Use /events?with_nested_markets=true to get readable event titles with their markets.
  2. Prices come as dollar strings, for example yes_bid_dollars "0.66", which means 66% implied.
  3. Page through with the cursor value from each response.

Copy-paste Python (standard library only)

import json, urllib.request

# events with their markets nested; one request = one page (use "cursor" for the next page)
url = "https://api.elections.kalshi.com/trade-api/v2/events?status=open&limit=20&with_nested_markets=true"
data = json.load(urllib.request.urlopen(url, timeout=30))

for e in data["events"][:5]:
    m = e["markets"][0]
    print(e["category"], "|", e["title"][:60], "| yes bid $", m["yes_bid_dollars"])
print("next page cursor present:", bool(data.get("cursor")))
