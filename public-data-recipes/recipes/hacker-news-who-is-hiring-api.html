Get every "Who is hiring?" post from Hacker News

Tested by hand on 2026-10-29 · No API key needed · Official docs

The monthly Ask HN: Who is hiring? thread has hundreds of job posts written by founders. The public Algolia HN API returns the whole thread in one call.

Endpoint

https://hn.algolia.com/api/v1/items/{thread_id}

Steps

  1. Find the latest thread: search stories by the whoishiring account with search_by_date.
  2. Fetch /items/<id>. Each top-level children[] entry is one job post, in HTML.
  3. Filter by keywords such as remote, python or visa, or have an LLM pull out company, role and location.

Copy-paste Python (standard library only)

import json, urllib.request

def get(url):
    return json.load(urllib.request.urlopen(url, timeout=30))

# 1. newest "Who is hiring?" thread posted by the whoishiring account
hits = get("https://hn.algolia.com/api/v1/search_by_date?tags=story,author_whoishiring&hitsPerPage=10")["hits"]
thread = next(h for h in hits if "Who is hiring" in h["title"])
print(thread["title"], thread["objectID"])

# 2. every top-level comment is one job post
item = get(f"https://hn.algolia.com/api/v1/items/{thread['objectID']}")
posts = [c for c in item["children"] if c.get("text")]
remote = [c for c in posts if "remote" in c["text"].lower()]
print(len(posts), "posts,", len(remote), "mention remote")

Last test result: The October 2026 thread returned 262 posts, and 147 mention “remote”.
