Get every open job from a Greenhouse job board (official JSON API)

Tested by hand on 2026-10-29 · No API key needed · Official docs

Thousands of companies host careers pages on Greenhouse. The Job Board API is public and read-only, needs no key, and returns every listed role as JSON.

Endpoint

https://boards-api.greenhouse.io/v1/boards/{board}/jobs

Steps

  1. Find the board slug: open the company's careers page. If it links to job-boards.greenhouse.io/<slug>, that slug is the board.
  2. Call /v1/boards/<slug>/jobs. Add ?content=true if you also need job descriptions.
  3. Each job has title, location.name, absolute_url, updated_at and first_published.

Copy-paste Python (standard library only)

import json, urllib.request

BOARD = "gitlab"  # the slug in job-boards.greenhouse.io/<slug>
url = f"https://boards-api.greenhouse.io/v1/boards/{BOARD}/jobs"
data = json.load(urllib.request.urlopen(url, timeout=30))

for job in data["jobs"][:5]:
    print(job["title"], "|", job["location"]["name"], "|", job["absolute_url"])
print(len(data["jobs"]), "open roles")

Last test result: 232 open roles returned for the board gitlab.
