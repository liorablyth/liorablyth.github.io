Read a company's Lever job postings as JSON

Tested by hand on 2026-10-29 · No API key needed · Official docs

Lever's postings API is the public feed behind jobs.lever.co pages. You don't need a key to read it.

Endpoint

https://api.lever.co/v0/postings/{company}?mode=json

Steps

  1. Get the slug from jobs.lever.co/<slug>.
  2. Call /v0/postings/<slug>?mode=json. Add &skip=0&limit=100 to page through long lists.
  3. Useful fields: text (title), categories.location, categories.team, hostedUrl, createdAt (ms epoch) and workplaceType.

Copy-paste Python (standard library only)

import json, urllib.request

COMPANY = "palantir"  # the slug in jobs.lever.co/<slug>
url = f"https://api.lever.co/v0/postings/{COMPANY}?mode=json"
jobs = json.load(urllib.request.urlopen(url, timeout=30))

for job in jobs[:5]:
    loc = job.get("categories", {}).get("location", "")
    print(job["text"], "|", loc, "|", job["hostedUrl"])
print(len(jobs), "open roles")

Last test result: 304 open roles returned for the company palantir.

Be a good citizen

  • Follow the provider's terms and rate limits. Make one request at a time and cache the results.
  • If you get 401, 403, 429 or a captcha, stop. Don't try to get around it.
  • Handle personal data under GDPR/CCPA. Collect only the fields you need.
