Query NYC building permits from NYC Open Data

Tested by hand on 2026-10-29 · No API key needed · Official docs

NYC publishes Department of Buildings (DOB NOW) approved permits as open data. You filter it with SoQL query parameters in the URL.

Endpoint

https://data.cityofnewyork.us/resource/rbx6-tga4.json

Steps

  1. Pick fields with $select, filter with $where and sort with $order.
  2. This dataset includes people's names. Leave them out unless you have a lawful reason to process them.
  3. For heavier use, register a free app token with NYC Open Data and send it as X-App-Token.

Copy-paste Python (standard library only)

import json, urllib.parse, urllib.request

# NYC DOB NOW: Build - Approved Permits (Socrata open data; no key needed for light use)
params = {
    "$select": "borough,work_type,permit_status,estimated_job_costs,zip_code,:updated_at",  # skip personal-name fields
    "$where": "borough = 'BROOKLYN'",
    "$order": ":updated_at DESC",
    "$limit": "5",
}
url = "https://data.cityofnewyork.us/resource/rbx6-tga4.json?" + urllib.parse.urlencode(params)
for row in json.load(urllib.request.urlopen(url, timeout=30)):
    print(row)
