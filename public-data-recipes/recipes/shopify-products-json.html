List a Shopify store's products with /products.json

Tested by hand on 2026-10-29 · No API key needed · Official docs

Most Shopify storefronts serve their public catalog at /products.json. It has titles, variants, prices and images, with no key needed.

Endpoint

https://{store}/products.json?limit=250&page={n}

Steps

  1. Check the store is on Shopify: /products.json returns JSON with a products array.
  2. Read pages with limit=250&page=N until a page comes back empty. Go one request at a time.
  3. Price lives in variants[].price. The product URL is /products/<handle>.
  4. Some stores turn this off or rate-limit it. If you get 404, 401 or 430, stop. Don't try to work around it.

Copy-paste Python (standard library only)

import json, urllib.request

STORE = "https://www.allbirds.com"  # any Shopify storefront
products, page = [], 1
while page <= 3:  # be polite: a few pages, one request at a time
    url = f"{STORE}/products.json?limit=250&page={page}"
    req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
    batch = json.load(urllib.request.urlopen(req, timeout=30))["products"]
    if not batch:
        break
    products += batch
    page += 1

for p in products[:5]:
    print(p["title"], "|", p["variants"][0]["price"], "|", f"{STORE}/products/{p['handle']}")
print(len(products), "products read")

Last test result: 356 products read from allbirds.com (3 pages).
