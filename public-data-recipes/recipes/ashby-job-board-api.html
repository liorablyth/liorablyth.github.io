Pull open roles from an Ashby job board

Tested by hand on 2026-10-29 · No API key needed · Official docs

Ashby's public posting API backs jobs.ashbyhq.com boards. It returns all listed jobs in one response.

Endpoint

https://api.ashbyhq.com/posting-api/job-board/{board}

Steps

  1. Take the slug from jobs.ashbyhq.com/<slug>.
  2. Send a normal User-Agent header. In our test, Python's default client got HTTP 403 without one.
  3. Fields: title, location, department, isRemote, workplaceType, jobUrl, publishedAt. Add ?includeCompensation=true for pay ranges where they're published.

Copy-paste Python (standard library only)

import json, urllib.request

BOARD = "ramp"  # the slug in jobs.ashbyhq.com/<slug>
url = f"https://api.ashbyhq.com/posting-api/job-board/{BOARD}"
req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
data = json.load(urllib.request.urlopen(req, timeout=60))

for job in data["jobs"][:5]:
    print(job["title"], "|", job["location"], "|", job["jobUrl"])
print(len(data["jobs"]), "open roles")

Last test result: 168 open roles returned for the board ramp.
