About

Public Data Recipes is a small project by Liora Tools. It gathers practical, tested ways to read public data from official endpoints.

How we use AI

  • AI tools helped draft the explanations, the example prompts and the site code.
  • A person ran every code sample against the live endpoint before it was published, and we note the test date on each page.
  • We don't mass-generate pages. If a recipe can't be tested, it doesn't go up.
